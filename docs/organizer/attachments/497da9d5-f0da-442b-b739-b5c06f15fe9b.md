Pokerbots
Protocol Specification
Discard Hold’em — stdin/stdout interface
Submission deadline: 15 November 2026, 23:59 IST
This specification is part of the Pokerbots Rulebook. Values marked (provisional) may be
adjusted after benchmarking. Corrections or clarifications to this specification are announced
to all teams.
1 Overview
A bot is a Python 3.11 program (bot.py) started fresh for every match. It communicates with
the match engine only through stdin (messages from the engine) and stdout (the bot’s replies).
There is no network, no file access and no other channel. The engine is authoritative: it deals
the cards, tracks the game state, enforces legality and runs the clock.
The game is heads-up no-limit Hold’em with two changes: each player receives three hole
cards, and after the flop betting each player discards one hole card, simultaneously and face
up. The game rules are in Section 4 of the Rulebook. The Problem Statement(which will be
released on 1st November) gives them in full with worked examples.
2 Transport and Format
• Encoding: UTF-8. One message per line, terminated by \n.
• Format: each line is a single JSON object with a "type" field.
• Direction: the engine writes to the bot’s stdin; the bot writes to its stdout.
• Flushing: the bot must flush stdout after every message (print(..., flush=True)). Un-
flushed output does not reach the engine and consumes time bank.
• stdout must contain only protocol messages. Any other line (including debug prints) is a
malformed message (Section 9).
• stderr may be used for debugging. It is captured, limited to 64 KB per match, and never
parsed.
• The bot reads one line at a time and replies only to a request (action_request or discard_request).
A reply sent when no request is outstanding is ignored.
• Forward compatibility: the bot must ignore message types and fields it does not recognise.
3 Conventions
• Cards are two-character strings: rank (2 3 4 5 6 7 8 9 T J Q K A) then suit (s h d c),
for example As, Td, 2c. Ace is high in rank comparisons.
• Chips are integers. Blinds are 1 and 2. Every hand starts with 200 chips per player (stacks
reset every hand).

• Seats are "button" (posts the small blind) and "big_blind". Seats alternate every hand.
• Streets are "preflop", "flop", "turn" and "river".
• Actors in history entries are "me" (the receiving bot) and "opp".
• Amounts for call and raise mean the total chips the actor has committed on the current
street after the action (a “to” amount), not the increment.
• The bot is not told which deals are duplicates of each other, and it keeps no state between
matches.
4 Message Flow
engine -> bot init (once per match)
repeat for each hand:
engine -> bot new_hand
engine -> bot action_request (preflop, each time the bot must act)
bot -> engine action
... flop betting ...
engine -> bot discard_request (once, only if nobody has folded)
bot -> engine discard (both players answer simultaneously)
engine -> bot discard_result
... turn and river betting ...
engine -> bot hand_result
engine -> bot match_end (once; the bot should then exit)
A hand can end early: if a player folds, the engine sends hand_result immediately and no
further requests follow. If a player folds before the flop betting ends, there is no discard. If both
players are all-in, the remaining board cards are dealt and the discard still takes place after the
flop.

5.3 action_request
The bot must answer with an action message.
Field Type Meaning
type str "action_request"
hand_id int current hand
street str current street
board list[str] community cards dealt so far
pot int total chips in the pot, including bets on this street
my_bet, opp_bet int chips each player has committed on this street
to_call int opp_bet − my_bet; 0 means checking is legal
my_stack, opp_stack int chips each player still has behind
legal_actions list[str] subset of fold, check, call, raise
min_raise, max_raise int legal range of raise-to amounts; present only if raise is
legal
raises_left int bets or raises still allowed on this street
history list[object] all voluntary actions this hand, oldest first (blinds are
not listed)
time_left_ms int remaining time bank
A history entry has the form {"street":"flop","actor":"opp","action":"raise","amount":6}.
amount is present for call and raise only.

hole_cards list[str] your 3 hole cards
board list[str] the 3 flop cards
pot int total chips in the pot

Field Type Meaning
type str "discard_result"
hand_id int current hand
my_discard str the card you discarded

5.6 hand_result
Field Type Meaning
type str "hand_result"
hand_id int hand number
result str "fold" or "showdown"
net int chips you won (positive) or lost (negative) this hand
board list[str] board cards dealt
my_hole_cards list[str] your remaining hole cards (3 if the hand ended before the

opp_hole_cards list[str] or null the opponent’s 2 remaining cards, only at showdown

history list[object] complete action history of the hand
5.7 notice
Informational only; no reply is expected.
Field Type Meaning
type str "notice"
code str "malformed", "illegal_action" or "illegal_discard"
applied str what the engine did instead, e.g. "check", "fold" or a card
5.8 match_end
Field Type Meaning
type str "match_end"
reason str "complete", "opp_forfeit" or "forfeit"
After match_end the bot should exit.

7 Legality Rules
• action must be one of legal_actions.
• fold is legal only when to_call > 0.
• check is legal only when to_call = 0.
• call is legal only when to_call > 0. It matches the opponent’s bet.
• raise (which also covers an opening bet) needs an integer amount with min_raise ≤ amount
≤ max_raise.
• min_raise = opp_bet + max(s, 2), where s is the size of the last bet or raise on this street.
With no bet yet the minimum is 2. The big blind counts as the first raise preflop, so the
first preflop minimum is 4.
• max_raise is the all-in amount: the most either player can have committed on this street.
If it is below the usual minimum, min_raise equals max_raise and only that all-in raise is
legal.
• At most 4 bets or raises are allowed per street (the big blind is the first one preflop). When
raises_left is 0, raise is not in legal_actions.
• A discard card must be one of the bot’s current 3 hole cards.
8 Time Limits (provisional)
• Time bank: one cumulative bank per match, not reset between hands: 60 seconds for a
400-hand Stage 1 match, 150 seconds for a Stage 2 match of about 1000 hands.
• What is charged: the time from when the engine sends an action_request or discard_request
until it receives the complete reply line. Both discard clocks run at the same time.
• Per reply: any single reply must arrive within 5 seconds.
• Start-up: 5 seconds from launch to being ready for init. This is not charged to the bank.
• Wall-clock kill: 180 seconds per match in Stage 1 and 450 seconds in Stage 2.
• time_left_ms is reported in every request so a bot can budget its computation.
• Resources: 1 vCPU, 1 GB RAM, no network, read-only filesystem.

11 Starter Bot (Python 3.11, standard library only)
import sys, json
RANKS = "23456789TJQKA"
def choose_action(req):
legal = req["legal_actions"]
# Replace with your strategy. This one checks if free, else calls.
if "check" in legal:
return {"type": "action", "action": "check"}
if "call" in legal:
return {"type": "action", "action": "call"}
return {"type": "action", "action": "fold"}
def choose_discard(req):
# Replace with your strategy. This one discards the lowest rank.
cards = req["hole_cards"]
worst = min(cards, key=lambda c: RANKS.index(c[0]))
return {"type": "discard", "card": worst}
def main():
for line in sys.stdin:
line = line.strip()
if not line:
continue
try:
msg = json.loads(line)
except ValueError:
continue
t = msg.get("type")
if t == "action_request":
reply = choose_action(msg)
elif t == "discard_request":
reply = choose_discard(msg)
elif t == "match_end":
break
else:
# init, new_hand, discard_result, hand_result, notice:
# update your own state here; no reply is sent.
continue
print(json.dumps(reply), flush=True)
if __name__ == "__main__":
main()
